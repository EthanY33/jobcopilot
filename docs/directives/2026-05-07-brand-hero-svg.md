### Animation content (single ~6s loop, plays continuously)

- Two ambient drift orbs (purely decorative, ambient — viewer should perceive presence, not motion):
  - Violet orb: HSL `258 90% 60%`, ~420×420 px, top-right anchor, opacity 0.5, blurred via SVG `<filter><feGaussianBlur stdDeviation="40">`, on an `<animateMotion>` path looping over ~30s

- Centered lockup, vertical center y≈160:
  - Logo tile (96×96): reuse the **exact** `tileSvg` markup from `apps/web/scripts/build-brand-assets.ts` (the `<linearGradient id="g">` + the `<mask id="m">` with the rotated orbit, then the `<rect>` filled with the gradient and masked). Inline it. Don't `<image href="...">` to a PNG.

"copilot" filled with a `<linearGradient>` whose `x1`/`x2` `<animate>` over 4s create a violet→azure sweep that loops continuously. Stop colors: violet HSL `258 90% 60%` and azure HSL `215 95% 50%`. Visual letter-spacing -0.025em (apply by tightening the path translate offsets at conversion time, since SVG paths don't have a letter-spacing knob).
- Tagline at y≈260: `AI drafts every piece of an application. You review and ship.` in a `<text>` element with system-bold-sans fallback (`-apple-system, system-ui, "Segoe UI", Roboto, sans-serif`, weight 500, size 22, fill `#f4f4f8` at 0.85 opacity). `<animate attributeName="opacity" from="0" to="1" begin="0s" dur="1.5s" fill="freeze">` so it fades in once and holds.

### Animation tech (constraints)

- **SMIL only** (`<animate>`, `<animateTransform>`, `<animateMotion>`, `<set>`). GitHub's SVG sanitizer strips `<style>`, `<script>`, and `@font-face`. SMIL survives.
- **No external font references.** The wordmark must be vector path data, not `<text>` referencing a font file. The tagline *can* be `<text>` with a system fallback because it's body copy and brand carry is concentrated in the wordmark.
- **No CSS keyframes.** Use `<animate>` with `dur`, `repeatCount="indefinite"`, and `keyTimes`/`keySplines` for easing (Bezier `0.4 0 0.2 1` ≈ ease-in-out).

### Wordmark path conversion (the only nontrivial step)

Use `opentype.js` (~80 KB devDep). Source font location to try in order:

1. `apps/web/node_modules/geist/dist/fonts/geist-sans/Geist[-Bold|-Black].ttf` (or `.otf`)
2. `apps/web/node_modules/geist/dist/fonts/geist-sans/Geist[-Bold|-Black].woff` — opentype.js parses WOFF directly
3. If only `.woff2` is present, fetch the TTF at script-run time from jsdelivr/fontsource (the existing `build-brand-assets.ts` already pulls Geist via jsdelivr in its OG template; reuse that URL). Cache the downloaded TTF in `apps/web/.brand-build/` (already in `.gitignore`).

Convert "jobcopilot" to one `<path d="...">` per glyph so "job" and "copilot" can take separate fills. Use `font.getPath(char, x, y, fontSize).toPathData(precision=2)` to extract `d` attributes. Track horizontal advance manually so the wordmark is laid out correctly with the -0.025em letter-spacing tightening.

The script (`build-brand-hero.ts`) lives in the repo for reproducibility — anyone can regenerate the SVG by running it.
